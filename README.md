A simple, real-time dashboard for comparing Bitcoin (BTC) and Bitcoin Cash (BCH) transaction fee estimates.

🔗 **Live website:** [bitcoinfees.live](https://bitcoinfees.live)

## Overview

Bitcoin Fees Live helps users quickly compare current transaction fees across the Bitcoin and Bitcoin Cash networks.

The dashboard displays:

- Next-block fee estimates
- Current median fee estimates
- BTC and BCH fee comparisons
- Fee estimates in USD
- Approximate fees based on an average transaction size of 145 virtual bytes
- The approximate time when fee data was last updated
- A Bitcoin Cash donation option to support the project

Fee data is refreshed approximately every two minutes using the mempool.space & blockchair.com APIs.

## Why Bitcoin Fees Live?

Transaction fees vary depending on network demand, mempool conditions, transaction size, and wallet configuration. Bitcoin Fees Live provides a quick way to compare current fee conditions between BTC and BCH before sending a transaction and allows you to see the difference in usability between BTC & BCH protocols. Bitcoin is a purely peer-to-peer version of electronic cash which allows online payments to be sent directly from one party to another without going through a financial institution. 

## Fee Metrics

### Next-block fee

The next-block fee is an estimate of the fee rate that may help a transaction confirm in the next available block.

### Median fee

The median fee represents the middle fee value among a selected group of recent transactions.

### USD estimates

Displayed USD values use an average transaction size of approximately 145 virtual bytes. Actual transaction fees vary depending on the transaction size, fee rate, exchange rate, wallet settings, and network conditions.

## Important Disclaimer

Fee estimates are probabilistic and are not guaranteed. Network conditions can change quickly, and displayed estimates may differ from the fee recommended by your wallet.

Always review the final fee in your wallet before broadcasting a transaction.
